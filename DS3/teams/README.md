# DS3 — Group 03: team work

Use your instructor-assigned `team-NN/` folder. One member creates its README listing members' GitHub usernames. Put collaborative labs under `team-NN/labs/LAB-ID/` and projects under `team-NN/projects/PROJECT-ID/`.

Each submission documents members' contributions and how to run and check the code. All teammates contribute through focused pull requests to this shared destination, following the [contribution guide](../../CONTRIBUTING.md).
